# 📺 Stranger Things: The Upside Down Experience
Uma landing page imersiva e totalmente responsiva que transporta os usuários para o universo sobrenatural de Hawkins. Este projeto foca em Storytelling Visual através de animações avançadas e uma interface que alterna entre o mundo real e o Mundo Invertido.

# 🚀 Funcionalidades Principais
The Upside Down Toggle: Um switch interativo que utiliza filtros de CSS e manipulação de DOM para transformar completamente a estética do site (cores, partículas e sons).
Animações de Scroll (Parallax): Elementos que ganham vida à medida que você explora a página, utilizando a biblioteca GSAP (GreenSock) para movimentos suaves.
Cartões de Personagens Interativos: Efeito de "glitch" ao passar o mouse (hover) e janelas modais para detalhes dos personagens.
Design Responsivo: Experiência otimizada para todas as telas, desde monitores 4K até dispositivos móveis, seguindo as diretrizes de Web Design Responsivo da MDN.

# 🛠️ Tecnologias Utilizadas
HTML5 & CSS3: Semântica avançada e variáveis CSS (Custom Properties) para o gerenciamento de temas.
JavaScript (ES6+): Lógica para os gatilhos de animação e alternância de estados.
AOS (Animate On Scroll): Para revelação gradual de seções.
Google Fonts: Implementação da icônica tipografia ITC Benguiat via integração web.
Biblioteca GSAP: instalando uma biblioteca javascript, via script, para fazer as animações. Os plugins instalados:
  * ScrollSmoother ->  cria rolagens suaves e fluidas (smooth scrolling) em sites.
  * ScrollTrigger -> cria animações baseadas na rolagem (scroll) da página de forma fácil, eficiente e performática.
  * SplitText -> projetado para dividir blocos de texto HTML (linhas, palavras ou caracteres) em elementos individuais (<div> ou <span>), permitindo animações avançadas e criativas.
